# 0.4.0 验证记录（待联机验收）

这是基于 0.3.1（GitHub `7b57432`）的本地测试版本，未推送仓库。

## 已验证

- 使用 JDK 25、Minecraft 26.1.2 实际客户端/通用类、Fabric API 0.149.0+26.1.2、AudioPlayer 2.2.0+26.1.2、Voice Chat API 2.6.0 正常编译并打包。
- `MeterInputCheck` 全部通过，覆盖双独立频道、GUI/世界共享分析、25/50 Hz 跳步、关闭 GUI 后继续世界分析、停止和过期清理、最近四个世界频道预算、GUI 优先及连接清理。Gradle 9.4.1 的新增独立检查任务也通过隔离验证。
- 使用 Fabric Loader 0.19.2、上述 Fabric API、AudioPlayer 和 Simple Voice Chat 2.6.15+26.1.1 启动真实 MC 26.1.2 客户端及集成服务端，使用独立测试探针注入两者共享的模拟播放快照及合成 PCM。检查东南西北四种朝向的正面 VFD、曲目编号 `07`、静态待机、暂停熄灭、超出 16 格或绕到背面后的订阅释放及回到近距离正面的恢复。客户端正常退出。测试探针未包含在发行 JAR 内。
- 独立 Fabric 专用服务端成功启动至 `Done`，随后正常关闭，没有加载客户端类导致的异常。
- 动态纯白纹理位于 `textures/entity/`，不降低方块图集 mipmap 级别。
