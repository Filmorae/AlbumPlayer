# 0.4.2 显示偏好与边框修复验证

- 主频谱右边框在 0.4.1 中使用近似屏幕底色，视觉上缺失；待机与播放贴图右侧 2 texels 改为与辅助模块一致的边框色，保持此前 128×128 的分段、数字及 UV 坐标不变。
- 频谱页面右上角新增两态像素图标（绿色带独立峰值、灰色无峰值），悬停中英文本说明，点击优先于切换唱片图。峰值暂留默认为开启，并应用于本人可见的 UI 与世界频谱，不改变柱状电平响应、FFT、订阅策略或其他客户端的显示。
- `AlbumClientSession` 三个布尔值保存当前客户端会话的偏好，不生成配置文件、不添加存档字段或联机消息。跨玩家的设置独立；跨播放机沿用同一客户端会话。切换页面即时保存并且唱片仓不覆盖其状态。
