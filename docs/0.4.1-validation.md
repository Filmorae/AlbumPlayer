# 0.4.1 测试修复记录

## 曲目编号外观

- 正面纹理提升至 128×128，频谱原位置、12×8 格数及动画逻辑不变。
- 在原有右侧栏中为双位数字屏和绿色播放状态灯设置对齐的完整四边框、相同宽度和保留木侧板前的间隙。
- 七段数字采用相同尺寸、等间距、居中的较窄长字形；底图与亮起几何的分段像素逐项匹配。

## Photon v1.4 法线贴图兼容性

- 0.4.0 的 `FrontDisplay` 所有顶点均使用 (0.5, 0.5)。即使颜色来自均匀白纹理，此退化 UV 会使 Iris 无法计算正常的切线；Photon 的 `get_tbn_matrix` 调用 `normalize(gl_NormalMatrix * at_tangent.xyz)`，法线贴图和方向光照会使用该矩阵，导致亮段被渲染成黑色。
- 0.4.1 保留自发光 RenderType，但为每个亮段提供非零面积的四角 UV。唱臂盒体原本也采用单点白色 UV，故同步修复，白色采样范围仍位于原有材质的白色区域。没有引入 Photon 专用代码、资源覆盖或修改用户配置。

## 实测

- 使用用户提交的 Photon v1.4 构建包、Iris 1.10.9、Sodium 0.8.12、Minecraft 26.1.2（JDK 25）。用户完整配置在本地 llvmpipe 的 32 KiB compute shared memory 限制下不能编译 Photon 的 deferred4_a 程序（需要约 36 KiB）。因此只在测试副本中关闭 SH_SKYLIGHT，保留原配置中 NORMAL_MAPPING、SPECULAR_MAPPING、DIRECTIONAL_LIGHTMAPS、POM、COLORED_LIGHTS 等所有相关开关，未改变 shader 源码。此为本地软件渲染测试限制，并非用户安装修复版时的设置要求。
- 通过播放快照与模拟 PCM 在真实游戏中复现 0.4.0 显示屏黑色，替换 0.4.1 后频谱及七段数字正常发光。见同场景截图比较 `photon-normal-mapping-comparison.png`。
- Iris/Sodium 保持安装但停用光影后，旧版集成探针再次验证东南西北四个方向、背面和超出 16 格后释放分析、返回正面恢复分析、暂停熄屏；全部通过。
- 维持 0.4.0 的 16 格可见距离、按需分析、独立频段缓存、峰值保持及待机策略；未修改网络、存档或播放协议。
- 依赖网络限制与上一版相同，使用真实 26.1.2 游戏类库和 JDK 25 直接编译及打包。最终版本的 MeterInputCheck 全部通过，专用服务端正常启动与关闭。实际联机和 GPU 全配置仍需用户环境验收。
