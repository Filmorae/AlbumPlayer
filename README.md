# AlbumPlayer · 专辑唱片机

AlbumPlayer 为 Minecraft Java 26.1.2 Fabric 添加了一台可装 27 张唱片的专辑唱片机。把录好音频的唱片按专辑顺序排进唱片仓，就能在同一台机器上选曲、暂停或拖动进度。

## 功能

- **唱片仓与曲目列表**。唱片仓为 3 行 9 列，曲目按槽位从左到右、从上到下排列。播放列表可以滚动、直接选曲，并会高亮当前曲目。
- **共享播放控制**。附近玩家听到同一台唱片机的定位音频。支持播放与暂停、上一首与下一首、进度跳转，以及播完即停、列表循环和单曲循环。
- **实时 VFD 频谱**。收起列表后，点击唱片图切换到 24 列竖向频谱，每列有 18 格和独立峰值保持。频谱响应当前唱片机的音频，再点一次回到唱片图。
- **可动盘面与唱臂**。盘体和中心色环采用唱片配色，盘片以 33⅓ RPM 顺时针转动。唱针随单曲进度由外向内移动，跳转时抬针换位，暂停时抬针悬停。附近玩家即使没有打开播放器，也能看到正确的唱针位置。

## 版本与依赖

当前支持以下组合。安装前请确认 Minecraft、AudioPlayer 和 AudioPlayer Blanks 的版本。

| 组件 | 版本 | 安装位置 |
| --- | --- | --- |
| Minecraft Java 和 Java 运行时 | Minecraft **26.1.2**，Java **25** | 客户端和服务端 |
| Fabric Loader 和 Fabric API | Loader **0.19.3**、Fabric API **0.151.0+26.1.2** 为该依赖组合的基准 | 客户端和服务端 |
| AlbumPlayer | **0.3.1**，游戏内名为「专辑唱片机」 | 客户端和服务端 |
| AudioPlayer | **2.2.0+26.1.2** | 服务端 |
| AudioPlayer Blanks | **26.1.2-1.0.2+unofficial**，为本项目验证过的私用 26.1.2 移植版 | 客户端和服务端 |
| Simple Voice Chat | **2.6.15+26.1.1** 为联机测试使用的版本 | 客户端和服务端 |

本项目的播放功能依赖上表中的 AudioPlayer 和 AudioPlayer Blanks 版本。AudioPlayer Blanks 私用移植版需另行取得。

**唱片仓只接受来自 AudioPlayer Blanks、且已通过 AudioPlayer 绑定音频的可播放唱片。当前暂不支持原版唱片，即使原版唱片已经绑定自定义音频。** 空白未录制唱片和山羊角也不能放进唱片仓。旧版存入的原版唱片可通过唱片仓取出。

## 游戏内使用

1. 用一个原版唱片机、一个铁锭和一个红石粉无序合成。也可在创造模式的「功能方块」找到，或运行 `/give @s album_jukebox:jukebox`。
2. 潜行右键打开唱片仓，按希望的顺序放入唱片。
3. 右键打开播放器。左下角切换曲目列表，右下角切换循环模式。播放中和暂停时均可拖动进度条，松手后提交跳转。
4. 关闭界面后，只要区块仍加载，唱片机就会继续播放。唱片和循环模式会保存，区块卸载或服务器重启后可重新开始播放。拆除机器会掉落仓内唱片。

## 从源码构建

在仓库根目录使用 JDK 25 运行 Gradle Wrapper。

```bash
./gradlew build
```

Windows 可运行 `gradlew.bat build`。成品位于 `build/libs/`。构建需要访问 Fabric、Maven Central、Modrinth Maven 和 Simple Voice Chat 的 Maven 仓库。开发与维护说明见 [Agent.md](Agent.md)。
